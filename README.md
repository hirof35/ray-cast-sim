2D Raycasting Simulation (2Dレイキャスト・シミュレーション)JavaScript (HTML5 Canvas) を使用して実装した、2Dレイキャスティングの視覚化シミュレーションです。

概要プレイヤーの位置から周囲に光線（Ray）を放射し、壁と衝突する地点をリアルタイムで計算・描画します。
レイキャスティングの基礎的なアルゴリズムを可視化することを目的に制作しました。
機能プレイヤー操作: W, A, S, D キーを使用して、画面内を移動・回転できます。
リアルタイムレンダリング: プレイヤーの視界（視野角60度）が壁に衝突する様子をリアルタイムで描画します。
衝突判定: 線分と線分の交差計算アルゴリズムを用いています。操作方法ブラウザでページを開き、キャンバス内をクリックしてフォーカスしてから以下のキーを入力してください。
W キー: 前進S キー: 後退A キー: 左回転D キー: 右回転技術スタックFrontend: HTML5 Canvas, JavaScript (Vanilla)Mathematical Concepts:三角関数 (Math.cos, Math.sin) によるベクトル計算線分交差判定（線分 $P_1P_2$ と $P_3P_4$ の交点計算）開発の経緯このプロジェクトは、ゲームエンジンの根幹技術である「レイキャスティング」の仕組みを理解するために作成しました。
今後は、衝突判定の最適化（四分木など）や、3D視点（擬似3Dレンダリング）の実装を計画しています。
